# GadgetsHub

GadgetsHub is a full-stack, multi-page web application built using modern front-end technologies.

The application allows users to explore, manage, and interact with electronic gadgets such as smartphones, laptops, headphones, and other consumer tech products.

## Project General Description

Project Description

GadgetsHub is an interactive platform where users can browse gadgets, view detailed specifications, and manage personalized data through user accounts.

The project demonstrates full-stack development concepts including:

- Component-based UI design (React + TypeScript)
- Authentication and authorization (Clerk)
- Backend API integration
- User-specific data management
- Scalable architecture

## High-Level User Stories
- As a user, I want to browse gadgets by category so I can easily find products of interest.
- As a logged-in user, I want to save gadgets to a wishlist so I can revisit them later.
- As a logged-in user, I want to compare multiple gadgets side-by-side to make informed decisions.


## Project Scope & Focus

GadgetsHub focuses on consumer electronics and emphasizes:

- Product discovery
- Personalized user experience
- Interactive UI components
- Scalable full-stack architecture

It is not a full e-commerce system, but a product exploration and comparison platform.
